# NAME

pgpid-qrscan - pgpid-qrscan scan QRcodes containing parts of PGP secrets from IMAGES or webcam, and import this secrets into a factory reset OpenPGP secured device (eg yubikey).

# SYNOPSIS

**pgpid-qrscan** \[*OPTIONS*\]\... \[*\--*\] \[*IMAGES*\]\...

# DESCRIPTION

pgpid-qrscan scan QRcodes containing parts of PGP secrets from IMAGES or
webcam, and import this secrets into a factory reset OpenPGP secured
device (eg yubikey).

# OPTIONS

**-c**, **\--camera** \[V4LDEVICE\] read the fragments off a camera
(default when no IMAGES given)

**-s**, **\--camera-size** WxH

:   ask the camera for that frame instead of 640x480

**-k**, **\--no-send**

:   don't send the public key (certificate) to any keyserver

**-v**, **\--verbose**

:   increase log verbosity: \...\<notice\[5\]\<info\[6\]\<debug\[7\]
    (current: 6)

**-q**, **\--quiet**

:   decrease log verbosity:
    \...\<err\[3\]\<warning\[4\]\<notice\[5\]\<\... (current: 6)

**-h**, **\--help**

:   show this help and exit

**-V**, **\--version**

:   show version and exit

# DIAGNOSTICS

Returns zero on normal operation, non-zero on errors. Each action names
its own codes under **--help** where it has any.
