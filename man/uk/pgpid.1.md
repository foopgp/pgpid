# NAME

pgpid - Читає сертифікати OpenPGP і діє над ними за взірцем pgpid: ідентифікатори сутностей, чинність, кредит довіри.

# SYNOPSIS

**pgpid** \[*OPTIONS*\]\... *ACTION *\[*ARGS*\]\...

# DESCRIPTION

Читає сертифікати OpenPGP і діє над ними за взірцем pgpid:
ідентифікатори сутностей, чинність, кредит довіри.

## ACTIONS:

list

:   Перелічити сертифікати в\'язки ключів

get

:   Знайти сертифікат, спершу оновивши його

property

:   Вивести властивість vCard сертифіката

sigs

:   Перелічити, хто засвідчив сертифікат

del

:   Вилучити сертифікати, лише за відбитком

avatar

:   Видобути зображення, яке несе сертифікат

push

:   Надіслати сертифікати на сервери ключів

gen_u4

:   Вивести ідентифікатор із громадянського стану чи паспорта

gen_uid

:   Вивести номер облікового запису Unix

to_vcard

:   Вивести сертифікат як vCard

email

:   Показати, додати чи відкликати несені адреси

certify

:   Поручитися за іншого

trustdb

:   Читати, публікувати й застосовувати кредит довіри до інших

gen_key

:   Створити пару ключів за взірцем PGP ID

change_passphrase

:   Змінити те, що захищає тут таємний ключ

token_check

:   Перевірити, що несе під\'єднаний ключ безпеки

token_retries

:   Спроби, що лишилися на кодах ключа

totoken

:   Перенести таємний ключ на ключ безпеки

change_token_code

:   Перевірити чи змінити його PIN або код Admin

change_token_meta

:   Записати, що він каже про свого власника

print_secret

:   Надрукувати таємний ключ на папері, фрагментами

scan

:   Зібрати його назад із фрагментів

print_card

:   Виготовити чи надрукувати наліпку або картку

## OPTIONS:

**-H**, **\--homedir** КАТАЛОГ

:   Каталог GnuPG - Змінна оточення: GNUPGHOME

**\--output-format**=*ФОРМАТ*

:   Формат виводу з {raw, info, md} - Типово: «raw»

**-h**, **\--help**

:   Вивести цю довідку й вийти

**-V**, **\--version**

:   Вивести версію й вийти

У кожної дії є свій **\--help**.

## pgpid list

```
Usage: pgpid list [OPTIONS]... [ЗРАЗОК]

Перелічує сертифікати в'язки ключів, по одному в рядку.

Стовпці:
відбиток, ідентифікатор сутності, адреса (головна), засвідчення
(необов'язково), чинність, довіра, дата_створення, дата_спливу,
дата_відкликання

Одиничне тире «-» означає приховане або невідоме значення.

Значення чинності: certified|uncertified|expired|revoked|broken|-
Порядок важливості для непридатних сертифікатів: broken>revoked>expired

Значення довіри: never|undefined|marginal|full|ultimate|-

ЗРАЗОК, якщо задано, передається рушієві як є; без нього перелічується
вся в'язка ключів.

OPTIONS:
  -S, --short                 Рядок на адресу: відбиток, ідентифікатор, адреса
                              Те, що відповідає «pgpid get --no-fetch», стовпець у стовпець
  -L, --no-check-eid          Давнє: не вважати «broken» сертифікат без узгодженого eid
      --count-certs           Порахувати різних засвідчувачів кожного сертифіката й заповнити стовпець *certifications* (може бути довго!)
      --hide-trust            Довіра (ownertrust) — чутлива величина, за якою рахується чинність; часом обидві мають лишитися особистими
      --machine-readable      Виводити час (секунди від епохи) замість дати (iso-8601) і позначки замість читаних слів
  -h, --help                  Вивести цю довідку й вийти
```

## pgpid get

```
Usage: pgpid get [OPTIONS]... ІМ'Я|U4|U5|АДРЕСА...

Виводить відбитки, адреси та eid сертифікатів, що відповідають
ІМ'Я|U4|U5|АДРЕСА.
Може також дістати чи оновити сертифікати з серверів ключів.
'*' означає всю вʼязку; `list` — та, що показує все, коли її ні про що не питають.

OPTIONS:
  -F, --fingerprint           Вивести лише відбитки
  -E, --email                 Вивести лише адреси
  -f, --no-fetch              Не оновлювати з серверів ключів і WKD
  -m, --errexit-g=1           Відмовити, якщо відповідає понад N сертифікатів
  -K, --keyservers KEYSERVERS Оновити з цих, через пробіл - Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

«cert_check» немає: `list` відповідає те саме, що й він, дешевше.

```

## pgpid property

```
Usage: pgpid property PROPERTY [OPTIONS]... [ІМ'Я|АДРЕСА|KEYID|U4|U5]

Показати, додати або відкликати uid властивостей vCard у сертифікаті OpenPGP.
PROPERTY — одне з: { name, note, address, phone, url, lang, geo, ksprefrd }.
Поштові адреси не є uid властивостей vCard (вони тримають вигляд
'Імʼя <адреса>', зрозумілий кожному поштовому клієнтові): ними опікується
'pgpid email'.
'ksprefrd' — це бажаний сервер сертифікатів. Він не зберігається як uid
властивості vCard, а вживається при створенні vCard: його можна замінити,
але не відкликати.
Немає ІМ'Я|АДРЕСА|KEYID|U4|U5 ⇒ сертифікат, чий таємний ключ під рукою.
Вільні значення (name, note) з , ; \ або переносами зберігаються екранованими
за RFC 6350 і розкодовуються при виводі (address тримає свою структурну ';')

OPTIONS:
  -A, --add VALUE             Додати значення (повторюване)
      --replace-to VALUE      Те саме слово, для тих, у кого значення одне
  -R, --revoke VALUE          Відкликати uid зі ЗНАЧЕННЯМ (повторюване)
      --revoke-all            Відкликати всі значення, крім найсвіжішого
  -y, --yes                   Вважати «так»: пропустити попередження
      --show-unusable         Показати також значення, що більше не чинні
  -K, --keyservers KEYSERVERS Надіслати змінений сертифікат на ці - Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Відкликання незворотне: OpenPGP зберігає uid на сертифікаті назавжди,
позначеним як відкликаний, і такого самого вже ніколи не додати.

```

## pgpid sigs

```
Usage: pgpid sigs [OPTIONS]... ВІДБИТОК

Перелічує, хто засвідчив цей сертифікат, від найдавнішого: дата,
ідентифікатор ключа, адреса. Ідентифікатор ключа — це те, що пошук бере,
щоб ступити далі в мережу довіри.

Читається лише uid особи (UID:urn:eid:...), бо засвідчення стосується
сутності, а не однієї з її адрес. Сертифікат без uid особи спадає на
зведений перелік, із повідомленням.

Власні підписи лишаються осторонь: вони роблять uid чинним, вони нікого
не засвідчують.

OPTIONS:
  -a, --all-uids              Звести підписи всіх uid
  -h, --help                  Вивести цю довідку й вийти
```

## pgpid del

```
Usage: pgpid del [OPTIONS]... ВІДБИТОК...

Вилучає сертифікати з в'язки ключів, разом із таємною частиною.

Приймаються лише відбитки — 40 або 64 шістнадцяткових знаки. Дія, що
вилучає, не вгадує, про який сертифікат ішлося.

OPTIONS:
  -s, --secret                Вилучити лише таємницю, сертифікат лишити
  -h, --help                  Вивести цю довідку й вийти
```

## pgpid avatar

```
Usage: pgpid avatar [OPTIONS]... [ІМʼЯ|АДРЕСА|KEYID|U4|U5]

Дістати зображення з сертифіката OpenPGP або додати його туди.
Немає ІМ'Я|АДРЕСА|KEYID|U4|U5 ⇒ перший таємний сертифікат.

  -K, --keyservers СЕРВЕРИ    Якщо не порожньо, надіслати змінений сертифікат на ці сервери - Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org

## pgpid gen_u4

```
Usage: pgpid gen_u4 [OPTIONS]...
   or: pgpid gen_u4 --from-passport-mrz [OPTIONS]... MRZ...

Створити рядок eid u4 з громадянського стану: останню частину прізвища, два
перші імені, дату народження й країну.

З --from-passport-mrz натомість подають машинозчитувану зону міжнародного
паспорта — 88 знаків у двох рядках, пробіли й переноси пропускаються, тож її
можна вставити так, як зчитано. Чотири опції нижче й далі діють поряд і
заступають те, що каже зона: так виправляють прізвище, врізане, щоб
умістилося, не переписуючи решти.

OPTIONS:
  -s, --surname SURNAME       Прізвище при народженні
  -g, --given-names GIVEN_NAMES Імена при народженні, через пробіл або кому
  -d, --birth-date            РРРР-ММ-ДД      Дата народження
  -c, --birth-country COUNTRY_CODE Трилітерний код країни місця народження
      --from-passport-mrz     Читати громадянський стан із зони, заданої аргументами
  -u, --uncheck               Із зоною: повідомити про хибну контрольну цифру
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Набране вручну — потрібне все: питати про те, чого бракує, — справа того, у
кого є в кого спитати. З паспорта — нічого, і варто додати хіба --birth-date,
якщо двох цифр не досить.

Є ~20% імовірності, що *u4*, створене з паспорта, хибне: прізвище, врізане,
щоб умістилося, імʼя, змінене після народження, інша транслітерація, або рік
народження, який двом цифрам не розмістити. Перевірте його.
```

## pgpid gen_uid

```
Usage: pgpid gen_uid [OPTIONS]... U4|U5|РЯДОК

Створити 32-бітний ідентифікатор користувача Unix, від 2^18 до (2^31)-2

OPTIONS:

  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Аргумент обовʼязковий: питати громадянський стан в діалозі — справа того,
хто викликає.
```

## pgpid certify

```
Usage: pgpid certify [OPTIONS]... TARGET_KEYFPR [TARGET_U4|TARGET_U5]

Засвідчити когось іншого, названого відбитком його ключа TARGET_KEYFPR.
Усі сорок знаків, зчитані з картки тієї особи й звірені з нею — ніколи не
взірець пошуку, бо засвідчення не забрати назад. Якщо подано ще й
TARGET_U4, сертифікат має його нести, інакше буде відмова.

Засвідчити означає: я знаю, що цей інший сертифікат належить цій справжній особі.
Це вимагає перевірити громадянський стан і відбиток відкритого ключа ЦІЛІ.
Це дозволяє поширити й зміцнити вашу мережу довіри та мережі ваших близьких.
Це зобовʼязання: що більше ви засвідчуєте, то більше зростає ваша репутація,
але зробивши це погано, ви зруйнуєте свою добру славу.

OPTIONS:
  -u, --use-privkey NAME|KEYID Засвідчити цим ключем
  -E, --all-emails            Засвідчити також кожен uid з адресою,
  -R, --revoke                Відкликати свої попередні засвідчення
  -o, --credibility VALUE     Наскільки вони, своєю чергою, засвідчують інших
      --ownertrust VALUE      Те саме, під назвою, яку дає gpg
  -l, --local                 Засвідчити без вивезення — корисно для проб
  -K, --keyservers KEYSERVERS Надіслати підсумок на ці, через пробіл - Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Значення, що повертається:
-   0 Без помилок
-   2 Помилка доводу чи вжитку
- 140 Немає чим засвідчувати — укажіть ключ через --use-privkey
- 141 Жоден сертифікат не несе цей відбиток
- 142 Засвідчувати самого себе — не новина! ;-)
- 143 Цей сертифікат не несе цей ідентифікатор

```

## pgpid trustdb

```
Usage: pgpid trustdb local|export|import [OPTIONS]... [ВІДБИТОК|OWNERTRUSTS.GPG]...

Читає кредит довіри до інших і переносить його далі.

  local    Що ця машина каже про задані сертифікати, або про кожен із них,
           коли не названо жодного.
  export   Те саме, підписане, щоб інші могли це відтворити. Пише у stdout.
  import   Застосувати підписане іншими, дістаючи названі ним ключі.
           Порядок входить у зміст: той, хто підписав, має бути вже чинним,
           коли надійде його черга, а кожен файл зважується щодо того,
           що вирішив попередній.

OPTIONS:
  -r, --replace-to ЗНАЧЕННЯ   local: призначити замість виводу — потребує
                              щонайменше одного відбитка
      --long                  local: також ідентифікатор і головну адресу
      --check                 local, import: перерахувати мережу довіри
      --update                те саме, питаючи про невирішені ключі
      --export-file ФАЙЛ      export: писати туди, а не у stdout
  -u, --use-privkey ІМʼЯ|KEYID  export: підписати цим ключем
      --export-all            export: узяти також ultimate і unknown
      --armor                 export: ASCII, а не двійкове, щоб покласти в git
      --import-fetch-all      import: дістати чи оновити всі названі ключі,
                              не лише ті, яких тут бракує
  -K, --keyservers СЕРВЕРИ    import: питати цих, через пробіл — порожньо,
                              щоб не питати нікого
  -q, --quiet                 Лише помилки й попередження
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти
```

## pgpid totoken

```
Usage: pgpid totoken [OPTIONS]... KEY_ID|FPR

Перенести таємниці OpenPGP на ключ безпеки (картку OpenPGP).
Ключ безпеки (картка OpenPGP) має бути приєднаний.
Виводить сертифікат OpenPGP в ASCII-обладунку, код PIN і код admin.

Це стирає картку й забирає таємні частини з цієї машини. І те, й інше

  -U, --certurl URL           Звідки можна отримати сертифікат
  -L, --lang LANG             Бажана мова картки - Типово: з локалі
  -k, --keyserver KEYSERVER   Надіслати туди сертифікат і побудувати з цього
  -K, --pubkey FILE           Записати туди також сертифікат у броні
      --force                 Стерти картку, яка не порожня
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

## pgpid print_secret

```
Usage: pgpid print_secret [OPTIONS]... KEY_ID|FPR

Вивантажити й надрукувати таємниці OpenPGP на кількох QR-кодах поділом
таємниці за Шаміром, так поділені, щоб жоден аркуш не ніс ключа.

OPTIONS:
  -p, --passphrase PASSPHRASE Фраза, що захищає таємні частини
  -P, --passfrom FILE         Прочитати її з першого рядка ФАЙЛУ
  -t, --printer PRINTER       Куди друкувати. Порожньо — виготовити аркуші
  -w, --with-passphrase       Надрукувати фразу поруч із QR-кодами
  -W, --workdir DIRECTORY     Працювати тут, а не в тимчасовому
  -S, --split NUM             Фрагментів, від 3 до 10 - Типово: 5
  -T, --threshold NUM         Фрагментів для збирання - Типово: 3
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Заувага: кількість фрагментів має бути більшою за поріг.
      Коли вони рівні, замість поділу Шаміра йде просте розрізання,
      і весь захист таємниці лежить на паролі.
      Інакше кажучи: коли (фрагменти == поріг), не ставити пароля або
      надрукувати його — ДУЖЕ НЕБЕЗПЕЧНО.

Світлини в друк не йдуть. Резервній копії ваше обличчя не потрібне, а
папір бере до рук той, хто його знайде.

```
