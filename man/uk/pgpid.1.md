# NAME

pgpid - Читає сертифікати OpenPGP і діє над ними за взірцем pgpid: ідентифікатори сутностей, чинність, кредит довіри.

# SYNOPSIS

**pgpid** \[*OPTIONS*\]\... *ACTION *\[*ARGS*\]\...

# DESCRIPTION

Читає сертифікати OpenPGP і діє над ними за взірцем pgpid:
ідентифікатори сутностей, чинність, кредит довіри.

## ACTIONS:

list

:   Перелічити сертифікати в\'язки ключів

get

:   Знайти сертифікат, спершу оновивши його

property

:   Вивести властивість vCard сертифіката

sigs

:   Перелічити, хто засвідчив сертифікат

del

:   Вилучити сертифікати, лише за відбитком

avatar

:   Видобути зображення, яке несе сертифікат

push

:   Надіслати сертифікати на сервери ключів

gen_u4

:   Вивести ідентифікатор із громадянського стану чи паспорта

gen_uid

:   Вивести номер облікового запису Unix

to_vcard

:   Вивести сертифікат як vCard

email

:   Показати, додати чи відкликати несені адреси

certify

:   Поручитися за іншого

trustdb

:   Читати, публікувати й застосовувати кредит довіри до інших

gen_key

:   Створити пару ключів за взірцем PGP ID

change_passphrase

:   Змінити те, що захищає тут таємний ключ

token_check

:   Перевірити, що несе під\'єднаний ключ безпеки

token_retries

:   Спроби, що лишилися на кодах ключа

totoken

:   Перенести таємний ключ на ключ безпеки

change_token_code

:   Перевірити чи змінити його PIN або код Admin

change_token_meta

:   Записати, що він каже про свого власника

print_secret

:   Надрукувати таємний ключ на папері, фрагментами

scan

:   Зібрати його назад із фрагментів

print_card

:   Виготовити чи надрукувати наліпку або картку

## OPTIONS:

**-H**, **\--homedir** КАТАЛОГ

:   Каталог GnuPG - Змінна оточення: GNUPGHOME

**\--output-format**=*ФОРМАТ*

:   Формат виводу з {raw, info, md} - Типово: «raw»

**-h**, **\--help**

:   Вивести цю довідку й вийти

**-V**, **\--version**

:   Вивести версію й вийти

У кожної дії є свій **\--help**.

## pgpid list

```
Usage: pgpid list [OPTIONS]... [ЗРАЗОК]

Перелічує сертифікати в'язки ключів, по одному в рядку.

Стовпці:
відбиток, ідентифікатор сутності, адреса (головна), засвідчення
(необов'язково), чинність, довіра, дата_створення, дата_спливу,
дата_відкликання

Одиничне тире «-» означає приховане або невідоме значення.

Значення чинності: certified|uncertified|expired|revoked|broken|-
Порядок важливості для непридатних сертифікатів: broken>revoked>expired

Значення довіри: never|undefined|marginal|full|ultimate|-

ЗРАЗОК, якщо задано, передається рушієві як є; без нього перелічується
вся в'язка ключів.

OPTIONS:
  -S, --short                 Рядок на адресу: відбиток, ідентифікатор, адреса
                              Те, що відповідає «pgpid get --no-fetch», стовпець у стовпець
  -L, --no-check-eid          Давнє: не вважати «broken» сертифікат без узгодженого eid
      --count-certs           Порахувати різних засвідчувачів кожного сертифіката й заповнити стовпець *certifications* (може бути довго!)
      --hide-trust            Довіра (ownertrust) — чутлива величина, за якою рахується чинність; часом обидві мають лишитися особистими
      --machine-readable      Виводити час (секунди від епохи) замість дати (iso-8601) і позначки замість читаних слів
  -h, --help                  Вивести цю довідку й вийти
```

## pgpid get

```
Usage: pgpid get [OPTIONS]... ІМ'Я|АДРЕСА|KEYID|U4|U5|'*'

Виводить відбитки, адреси та ідентифікатори сутностей сертифікатів, що
відповідають запиту, по рядку на адресу. Спершу оновлює їх із серверів
ключів, якщо не сказано інакше.

Потрібен зразок пошуку — «*» для всієї в'язки ключів. Саме `list`
показує все, коли в нього нічого не просять.

OPTIONS:
  -F, --fingerprint           Вивести лише відбитки
  -E, --email                 Вивести лише адреси
  -f, --no-fetch              Не оновлювати з серверів ключів і WKD
  -m, --errexit-g=N           Відмовити, якщо відповідає понад N сертифікатів
  -K, --keyservers СЕРВЕРИ    Оновити з цих, через пробіл
                              Порожньо — з жодного, як --no-fetch. Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

«cert_check» немає: `list` відповідає те саме, що й він, дешевше.
```

## pgpid property

```
Usage: pgpid property ІМ'Я [OPTIONS]... [ЗРАЗОК]

Показує значення однієї властивості vCard, яку несе сертифікат, по одному
в рядку, або додає й відкликає їх. Без ЗРАЗКА — сертифікат, чий таємний
ключ під рукою, тобто під'єднаний ключ безпеки.

ІМ'Я — одне з: name, note, phone, address, url, lang, geo, ksprefrd.
name і note несуть одне значення: додати одне — відкликати попереднє.
Сертифікат завжди зберігає принаймні одне ім'я.

Адреси — не властивості vCard: вони зберігають вигляд «Ім'я <адреса>»,
який читає будь-яка поштова програма. Для них «pgpid email».

«ksprefrd» — сервер сертифікатів, який цей сертифікат зве своїм. Це
підпакет підпису, а не uid: його заступають, але ніколи не відкликають.

OPTIONS:
  -A, --add ЗНАЧЕННЯ          Додати значення (повторюване)
      --replace-to ЗНАЧЕННЯ   Те саме слово, для тих, у кого значення одне
  -R, --revoke ЗНАЧЕННЯ       Відкликати uid зі ЗНАЧЕННЯМ (повторюване)
      --revoke-all            Відкликати всі значення, крім найсвіжішого
                              там, де одне має лишитися
  -y, --yes                   Вважати «так»: пропустити попередження
      --show-unusable         Показати також значення, що більше не чинні
  -K, --keyservers СЕРВЕРИ    Надіслати змінений сертифікат на ці
                              Порожньо — на жоден. Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Відкликання незворотне: OpenPGP зберігає uid на сертифікаті назавжди,
позначеним як відкликаний, і такого самого вже ніколи не додати.
```

## pgpid sigs

```
Usage: pgpid sigs [OPTIONS]... ВІДБИТОК

Перелічує, хто засвідчив цей сертифікат, від найдавнішого: дата,
ідентифікатор ключа, адреса. Ідентифікатор ключа — це те, що пошук бере,
щоб ступити далі в мережу довіри.

Читається лише uid особи (UID:urn:eid:...), бо засвідчення стосується
сутності, а не однієї з її адрес. Сертифікат без uid особи спадає на
зведений перелік, із повідомленням.

Власні підписи лишаються осторонь: вони роблять uid чинним, вони нікого
не засвідчують.

OPTIONS:
  -a, --all-uids              Звести підписи всіх uid
  -h, --help                  Вивести цю довідку й вийти
```

## pgpid del

```
Usage: pgpid del [OPTIONS]... ВІДБИТОК...

Вилучає сертифікати з в'язки ключів, разом із таємною частиною.

Приймаються лише відбитки — 40 або 64 шістнадцяткових знаки. Дія, що
вилучає, не вгадує, про який сертифікат ішлося.

OPTIONS:
  -s, --secret                Вилучити лише таємницю, сертифікат лишити
  -h, --help                  Вивести цю довідку й вийти
```

## pgpid avatar

```
Usage: pgpid avatar [OPTIONS]... [ІМ'Я|АДРЕСА|KEYID|U4|U5]

Видобуває зображення, яке несе сертифікат OpenPGP, і виводить шлях до
нього. Те, що чинне сьогодні, іде першим: перший рядок — це аватар. Без
добору — перший таємний сертифікат.

Запис потребує таємного ключа сертифіката і приймає лише відбиток:
відкликання не скасувати, тож пошук ніколи не має ставати ціллю. Нове
зображення спершу зводиться до 180x180, а змінений сертифікат надсилають
на типові сервери ключів, якщо не сказано інакше.

OPTIONS:
  -E, --extract-all           Вивести всі зображення, разом із відкликаними
  -A, --replace-to ЗОБРАЖ.    Зняти чинні зображення й покласти ЗОБРАЖ.
  -R, --revoke                Лише зняти чинні зображення
  -K, --keyservers СЕРВЕРИ    Надіслати змінений сертифікат на ці, через
                              пробіл. Порожньо — на жоден. Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -W, --workdir КАТАЛОГ       Куди пишуться зображення
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти
```

## pgpid gen_u4

```
Usage: pgpid gen_u4 [OPTIONS]...
   or: pgpid gen_u4 --from-passport-mrz [OPTIONS]... MRZ...

Виводить ідентифікатор сутності, який дає громадянський стан: останню
частину прізвища, два перші імені, дату народження й країну.

З --from-passport-mrz ці чотири читаються з машинозчитуваної зони
паспорта — 88 знаків у двох рядках, пробіли й переноси пропускаються,
тож її можна вставити так, як зчитано. Чотири опції вище й далі діють
поряд і заступають те, що каже зона: так виправляють прізвище, врізане,
щоб умістилося, не переписуючи решти.

OPTIONS:
  -s, --surname ПРІЗВИЩЕ           Прізвище при народженні
  -g, --given-names ІМЕНА          Імена при народженні, через пробіл або кому
  -d, --birth-date РРРР-ММ-ДД      Дата народження
  -c, --birth-country КОД          Трилітерний код країни місця народження
      --from-passport-mrz          Читати громадянський стан із зони, заданої аргументами
  -u, --uncheck                    Із зоною: повідомити про хибну контрольну цифру
  -h, --help                       Вивести цю довідку й вийти
  -V, --version                    Вивести версію й вийти

Набране вручну — потрібне все: питати про те, чого бракує, — справа того,
у кого є в кого спитати. З паспорта — нічого, а --birth-date все одно
варто додати, якщо двох цифр не досить.

Приблизно кожен п'ятий паспорт дає хибний ідентифікатор: прізвище,
врізане, щоб умістилося, ім'я, змінене після народження, інша
транслітерація, або рік, який двом цифрам не розмістити. Це треба
перевіряти.
```

## pgpid gen_uid

```
Usage: pgpid gen_uid [OPTIONS]... U4|U5|РЯДОК

Виводить номер облікового запису Unix, який дає ідентифікатор сутності,
між 262144 і 2147483646. Той самий ідентифікатор завжди дає той самий номер, на
будь-якій машині — саме це й дозволяє відкрити обліковий запис деінде за
одним лише сертифікатом.

OPTIONS:
  -f, --free-input            Прийняти будь-який рядок, не лише ідентифікатор
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Питати громадянський стан у розмові — справа того, хто викликає: це
читає, що йому дали, і нічого більше.
```

## pgpid email

```
Usage: pgpid email [OPTIONS]... [ІМ'Я|АДРЕСА|KEYID|U4|U5]

Показує адреси, які несе сертифікат, або додає й відкликає їх. Без цілі —
той, якому належить під'єднана картка.

      --revoke-all            Відкликати всі адреси, крім найсвіжішої
  -y, --yes                   Вважати «так»: пропустити попередження
  -N, --name ІМ'Я             Ім'я перед доданою адресою
                              Типово: FN: сертифіката, інакше місцева частина
  -c, --certs-count           Рахувати також засвідчення кожної адреси
      --show-unusable         Показати також адреси, що більше не чинні
      --info                  Вивести пари ключ=значення, придатні для bash
  -K, --keyservers СЕРВЕРИ    Надіслати змінений сертифікат на ці
                              Порожньо — на жоден. Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти

Відкликання незворотне: OpenPGP зберігає адресу на сертифікаті назавжди,
позначеною як відкликана, і такої самої вже ніколи не додати.
```

## pgpid certify

```
Usage: pgpid certify [OPTIONS]... ВІДБИТОК [U4|U5]

Поручитися за іншого: заявити, що цей сертифікат належить йому.

ВІДБИТОК — це відбиток повністю, сорок знаків, зчитаний з картки іншої
людини і з нею звірений — ніколи не зразок пошуку, бо засвідчення не
відкликається. Зазначення ще й ідентифікатора вимагає, щоб сертифікат
його ніс, і відмовляє інакше.

Засвідчення зобов'язує. Воно будує ваше добре ім'я і витрачає його, якщо
робити це не дивлячись.

OPTIONS:
  -u, --use-privkey ІМ'Я|KEYID  Засвідчити цим ключем
                                Типово: той, якому належить картка
  -E, --all-emails              Засвідчити також кожен uid з адресою,
                                для програм, що чекають її там
  -R, --revoke                  Відкликати свої попередні засвідчення
  -o, --credibility ЗНАЧЕННЯ    Наскільки вони, своєю чергою, засвідчують інших
      --ownertrust ЗНАЧЕННЯ     Те саме, під назвою, яку дає gpg
                                {undefined,marginal,full,never} — типово: marginal
  -l, --local                   Засвідчити без вивезення — корисно для проб
  -K, --keyservers СЕРВЕРИ      Надіслати підсумок на ці, через пробіл
                                Порожньо — на жоден. Типово: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                    Вивести цю довідку й вийти
  -V, --version                 Вивести версію й вийти

Значення, що повертається:
-   0 Без помилок
-   2 Помилка доводу чи вжитку
- 140 Немає чим засвідчувати — укажіть ключ через --use-privkey
- 141 Жоден сертифікат не несе цей відбиток
- 142 Засвідчувати самого себе — не новина! ;-)
- 143 Цей сертифікат не несе цей ідентифікатор
```

## pgpid trustdb

```
Usage: pgpid trustdb local|export|import [OPTIONS]... [ВІДБИТОК|OWNERTRUSTS.GPG]...

Читає кредит довіри до інших і переносить його далі.

  local    Що ця машина каже про задані сертифікати, або про кожен із них,
           коли не названо жодного.
  export   Те саме, підписане, щоб інші могли це відтворити. Пише у stdout.
  import   Застосувати підписане іншими, дістаючи названі ним ключі.
           Порядок входить у зміст: той, хто підписав, має бути вже чинним,
           коли надійде його черга, а кожен файл зважується щодо того,
           що вирішив попередній.

OPTIONS:
  -r, --replace-to ЗНАЧЕННЯ   local: призначити замість виводу — потребує
                              щонайменше одного відбитка
      --long                  local: також ідентифікатор і головну адресу
      --export-file ФАЙЛ      export: писати туди, а не у stdout
  -u, --use-privkey ІМʼЯ|KEYID  export: підписати цим ключем
      --export-all            export: узяти також ultimate і unknown
      --armor                 export: ASCII, а не двійкове, щоб покласти в git
      --import-fetch-all      import: дістати чи оновити всі названі ключі,
                              не лише ті, яких тут бракує
  -K, --keyservers СЕРВЕРИ    import: питати цих, через пробіл — порожньо,
                              щоб не питати нікого
      --check                 Перерахувати, не питаючи про решту
      --update                Перерахувати, питаючи про решту
  -q, --quiet                 Лише помилки й попередження
  -h, --help                  Вивести цю довідку й вийти
  -V, --version               Вивести версію й вийти
```

## pgpid print_secret

```
Usage: pgpid print_secret [OPTIONS]... КЛЮЧ

Друкує таємний ключ OpenPGP як QR-коди, поділений так, щоб жоден аркуш
не ніс його сам. Типово п'ять фрагментів, будь-які три з яких його
відновлюють.

OPTIONS:
  -p, --passphrase ФРАЗА         Фраза, що захищає таємні частини
  -P, --passfrom ФАЙЛ            Прочитати її з першого рядка ФАЙЛУ
  -t, --printer ПРИНТЕР          Куди друкувати. Порожньо — виготовити аркуші
                                 й нічого не надсилати, вони лишаються на місці
  -w, --with-passphrase          Надрукувати фразу поруч із QR-кодами
                                 Зручніше, і таємниця більше не поділена
  -W, --workdir КАТАЛОГ          Працювати тут, а не в тимчасовому
                                 Його вміст доведеться потім знищити
  -S, --split ЧИСЛО              Фрагментів до виготовлення - Типово: 5
  -T, --threshold ЧИСЛО          Фрагментів для збирання - Типово: 3
  -h, --help                     Вивести цю довідку й вийти
  -V, --version                  Вивести версію й вийти

Коли --split дорівнює --threshold, поділу таємниці немає: фрагменти — це
шматки поспіль, і кожен видає свою частину. Усе тримається тоді на
парольній фразі, а надрукувати її поруч — не лишити нічого.

Світлини в друк не йдуть. Резервній копії ваше обличчя не потрібне, а
папір бере до рук той, хто його знайде.
```
