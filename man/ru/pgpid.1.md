# NAME

pgpid - Читает сертификаты OpenPGP и действует над ними по образцу pgpid: идентификаторы сущностей, действительность, кредит доверия.

# SYNOPSIS

**pgpid** \[*OPTIONS*\]\... *ACTION *\[*ARGS*\]\...

# DESCRIPTION

Читает сертификаты OpenPGP и действует над ними по образцу pgpid:
идентификаторы сущностей, действительность, кредит доверия.

## ACTIONS:

list

:   Перечислить сертификаты связки ключей

get

:   Найти сертификат, сперва обновив его

property

:   Вывести свойство vCard сертификата

sigs

:   Перечислить, кто заверил сертификат

del

:   Удалить сертификаты, только по отпечатку

avatar

:   Извлечь изображение, которое несёт сертификат

push

:   Отправить сертификаты на серверы ключей

gen_u4

:   Вывести идентификатор из гражданского состояния или паспорта

gen_uid

:   Вывести номер учётной записи Unix идентификатора

to_vcard

:   Вывести сертификат как vCard

email

:   Показать, добавить или отозвать несомые адреса

certify

:   Поручиться за другого

trustdb

:   Читать, публиковать и применять кредит доверия к другим

gen_key

:   Создать пару ключей по образцу PGP ID

change_passphrase

:   Сменить то, что защищает здесь секретный ключ

token_check

:   Проверить, что несёт подключённый ключ безопасности

token_retries

:   Оставшиеся попытки на кодах ключа

totoken

:   Перенести секретный ключ на ключ безопасности

change_token_code

:   Проверить или сменить его PIN либо код Admin

change_token_meta

:   Записать, что он говорит о своём владельце

print_secret

:   Напечатать секретный ключ на бумаге, фрагментами

scan

:   Собрать его обратно из фрагментов

print_card

:   Изготовить или напечатать наклейку либо карточку

## OPTIONS:

**-H**, **\--homedir** КАТАЛОГ

:   Каталог GnuPG - Переменная окружения: GNUPGHOME

**\--output-format**=*ФОРМАТ*

:   Формат вывода из {raw, info, md} - По умолч.: «raw»

**-h**, **\--help**

:   Вывести эту справку и выйти

**-V**, **\--version**

:   Вывести версию и выйти

У каждого действия есть свой **\--help**.

## pgpid list

```
Usage: pgpid list [OPTIONS]... [ОБРАЗЕЦ]

Перечисляет сертификаты связки ключей, по одному в строке.

Столбцы:
отпечаток, идентификатор сущности, адрес (главный), заверения
(необязательно), действительность, доверие, дата_создания,
дата_истечения, дата_отзыва

Одиночное тире «-» означает скрытое или неизвестное значение.

Значения действительности: certified|uncertified|expired|revoked|broken|-
Порядок важности для негодных сертификатов: broken>revoked>expired

Значения доверия: never|undefined|marginal|full|ultimate|-

ОБРАЗЕЦ, если задан, передаётся движку как есть; без него перечисляется
вся связка ключей.

OPTIONS:
  -S, --short                 Строка на адрес: отпечаток, идентификатор, адрес
                              То, что отвечает «pgpid get --no-fetch», столбец в столбец
  -L, --no-check-eid          Прежнее: не считать «broken» сертификат без внятного eid
      --count-certs           Сосчитать разных заверителей каждого сертификата и заполнить столбец *certifications* (может быть долго!)
      --hide-trust            Доверие (ownertrust) — чувствительная величина, по которой считается действительность; порой обе должны остаться личными
      --machine-readable      Выводить время (секунды от эпохи) вместо даты (iso-8601) и метки вместо читаемых слов
  -h, --help                  Вывести эту справку и выйти
```

## pgpid get

```
Usage: pgpid get [OPTIONS]... ИМЯ|U4|U5|АДРЕС...

Выводит отпечатки, адреса и eid сертификатов, отвечающих
ИМЯ|U4|U5|АДРЕС.
Может также достать или обновить сертификаты с серверов ключей.
'*' означает всю связку; `list` — та, что показывает всё, когда её ни о чём
не спрашивают.

OPTIONS:
  -F, --fingerprint           Вывести только отпечатки
  -E, --email                 Вывести только адреса
  -f, --no-fetch              Не обновлять с серверов ключей и WKD
  -m, --errexit-g=1           Отказать, если подходит более N сертификатов
  -K, --keyservers KEYSERVERS Обновить с этих, через пробел - По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

«cert_check» нет: `list` отвечает то же, что отвечал он, дешевле.

```

## pgpid property

```
Usage: pgpid property PROPERTY [OPTIONS]... [ИМЯ|АДРЕС|KEYID|U4|U5]

Показать, добавить или отозвать uid свойств vCard в сертификате OpenPGP.
PROPERTY — одно из: { name, note, address, phone, url, lang, geo, ksprefrd }.
Почтовые адреса не являются uid свойств vCard (они держат вид
'Имя <адрес>', понятный всякому почтовому клиенту): ими занимается
'pgpid email'.
'ksprefrd' — это предпочтительный сервер сертификатов. Он не хранится как uid
свойства vCard, а используется при создании vCard: его можно заменить, но не
отозвать.
Нет ИМЯ|АДРЕС|KEYID|U4|U5 ⇒ сертификат, чей секретный ключ под рукой.
Свободные значения (name, note) с , ; \ или переводами строк хранятся
экранированными по RFC 6350 и раскодируются при выводе (address держит свою
структурную ';')

OPTIONS:
  -A, --add VALUE             Добавить значение (повторяемо)
      --replace-to VALUE      То же слово, для тех, у кого значение одно
  -R, --revoke VALUE          Отозвать uid со ЗНАЧЕНИЕМ (повторяемо)
      --revoke-all            Отозвать все значения, кроме самого свежего
  -y, --yes                   Считать «да»: пропустить предупреждение
      --show-unusable         Показать также значения, которые не действуют
  -K, --keyservers KEYSERVERS Отправить изменённый сертификат на эти - По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Отзыв необратим: OpenPGP хранит uid на сертификате навсегда, помеченным
как отозванный, и такой же уже никогда не добавить.

```

## pgpid sigs

```
Usage: pgpid sigs [OPTIONS]... ОТПЕЧАТОК

Перечисляет, кто заверил этот сертификат, от самого старого: дата,
идентификатор ключа, адрес. Идентификатор ключа — это то, что поиск берёт,
чтобы шагнуть дальше в сеть доверия.

Читается только uid личности (UID:urn:eid:...), потому что заверение
касается сущности, а не одного из её адресов. Сертификат без uid личности
падает на сведённый список, с уведомлением.

Собственные подписи остаются в стороне: они делают uid действующим, они
никого не заверяют.

OPTIONS:
  -a, --all-uids              Свести подписи всех uid
  -h, --help                  Вывести эту справку и выйти
```

## pgpid del

```
Usage: pgpid del [OPTIONS]... ОТПЕЧАТОК...

Удаляет сертификаты из связки ключей, вместе с секретной частью.

Принимаются только отпечатки — 40 или 64 шестнадцатеричных знака.
Действие, которое удаляет, не угадывает, о каком сертификате шла речь.

OPTIONS:
  -s, --secret                Удалить только секрет, сертификат оставить
  -h, --help                  Вывести эту справку и выйти
```

## pgpid avatar

```
Usage: pgpid avatar [OPTIONS]... [ИМЯ|АДРЕС|KEYID|U4|U5]

Извлечь изображение из сертификата OpenPGP или добавить его туда.
Нет ИМЯ|АДРЕС|KEYID|U4|U5 ⇒ первый секретный сертификат.

  -K, --keyservers СЕРВЕРЫ    Если не пусто, отправить изменённый сертификат на эти серверы - По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org

## pgpid gen_u4

```
Usage: pgpid gen_u4 [OPTIONS]...
   or: pgpid gen_u4 --from-passport-mrz [OPTIONS]... MRZ...

Создать строку eid u4 из гражданского состояния: последнюю часть фамилии,
два первых имени, дату рождения и страну.

С --from-passport-mrz вместо этого передают машиночитаемую зону
международного паспорта — 88 знаков в двух строках, пробелы и переводы строк
пропускаются, поэтому её можно вставить как считали. Четыре опции ниже
действуют и рядом с ней, заменяя то, что говорит зона: так исправляют
фамилию, урезанную, чтобы уместиться, не переписывая остального.

OPTIONS:
  -s, --surname SURNAME       Фамилия при рождении
  -g, --given-names GIVEN_NAMES Имена при рождении, через пробел или запятую
  -d, --birth-date            ГГГГ-ММ-ДД      Дата рождения
  -c, --birth-country COUNTRY_CODE Трёхбуквенный код страны места рождения
      --from-passport-mrz     Читать гражданское состояние из зоны в аргументах
  -u, --uncheck               С зоной: сообщить о неверной контрольной цифре
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Набранное вручную — требуется всё: спрашивать о недостающем — дело того, у
кого есть кого спросить. Из паспорта — ничего, и стоит добавить разве что
--birth-date, если двух цифр не хватает.

Есть ~20% вероятности, что *u4*, созданный из паспорта, неверен: фамилия,
урезанная, чтобы уместиться, имя, изменённое после рождения, иная
транслитерация, или год рождения, который двум цифрам не разместить.
Проверьте его.
```

## pgpid gen_uid

```
Usage: pgpid gen_uid [OPTIONS]... U4|U5|СТРОКА

Создать 32-битный идентификатор пользователя Unix, от 2^18 до (2^31)-2
([262144,2147483646]).
Тот же идентификатор всегда даёт то же число, на любой машине — именно это
позволяет открыть учётную запись в другом месте по одному сертификату.

OPTIONS:
  -f, --free-input            Принять любую строку, не только идентификатор
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Аргумент обязателен: спрашивать гражданское состояние в диалоге — дело
вызывающего.
```

## pgpid certify

```
Usage: pgpid certify [OPTIONS]... TARGET_KEYFPR [TARGET_U4|TARGET_U5]

Заверить кого-то другого, названного отпечатком его ключа TARGET_KEYFPR.
Все сорок знаков, считанные с карты того человека и сверенные с ней —
никогда не образец поиска, ибо заверение не забрать назад. Если задан ещё
и TARGET_U4, сертификат обязан его нести, иначе отказ.

Заверить значит: я знаю, что этот другой сертификат принадлежит этому реальному человеку.
Это требует проверить гражданское состояние и отпечаток открытого ключа ЦЕЛИ.
Это позволяет расширить и укрепить вашу сеть доверия и сети ваших близких.
Это обязательство: чем больше вы заверяете, тем выше ваша репутация,
но сделав это плохо, вы разрушите своё доброе имя.

OPTIONS:
  -u, --use-privkey NAME|KEYID Заверить этим ключом
  -E, --all-emails            Заверить также каждый uid с адресом,
  -R, --revoke                Отозвать свои прежние заверения
  -o, --credibility VALUE     Насколько они, в свою очередь, заверяют других
      --ownertrust VALUE      То же, под именем, которое даёт gpg
  -l, --local                 Заверить без вывоза — полезно для проб
  -K, --keyservers KEYSERVERS Отправить итог на эти, через пробел - По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Возвращаемое значение:
-   0 Без ошибок
-   2 Ошибка довода или употребления
- 140 Нечем заверять — укажите ключ через --use-privkey
- 141 Ни один сертификат не несёт этот отпечаток
- 142 Заверять самого себя — не новость! ;-)
- 143 Этот сертификат не несёт этот идентификатор

```

## pgpid trustdb

```
Usage: pgpid trustdb local|export|import [OPTIONS]... [ОТПЕЧАТОК|OWNERTRUSTS.GPG]...

Читает кредит доверия к другим и переносит его дальше.

  local    Что эта машина говорит о заданных сертификатах, или о каждом из
           них, когда не назван ни один.
  export   То же, подписанное, чтобы другие могли это воспроизвести. В stdout.
  import   Применить подписанное другими, доставая названные им ключи.
           Порядок входит в смысл: подписавший должен быть уже действителен,
           когда придёт его черёд, а каждый файл взвешивается относительно
           того, что решил предыдущий.

OPTIONS:
  -r, --replace-to ЗНАЧЕНИЕ   local: назначить вместо вывода — требует
                              хотя бы одного отпечатка
      --long                  local: также идентификатор и главный адрес
      --export-file ФАЙЛ      export: писать туда, а не в stdout
  -u, --use-privkey ИМЯ|KEYID  export: подписать этим ключом
      --export-all            export: взять также ultimate и unknown
      --armor                 export: ASCII, а не двоичное, чтобы положить в git
      --import-fetch-all      import: достать или обновить все названные ключи,
                              не только недостающие здесь
  -K, --keyservers СЕРВЕРЫ    import: спрашивать эти, через пробел — пусто,
                              чтобы не спрашивать никого
      --check                 Пересчитать, не спрашивая об остальных
      --update                Пересчитать, спрашивая об остальных
  -q, --quiet                 Только ошибки и предупреждения
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти
```

## pgpid gen_key

```
Usage: pgpid gen_key [OPTIONS]... АДРЕС

Создать пару ключей OpenPGP (открытый и секретный) по нормам PGP ID.
Выводит 3 строки, по одной на отпечаток:
* главный ключ (Подпись Заверение)
* ключ расшифрования (Шифрование)
* ключ проверки подлинности (Auth)

OPTIONS:
  -N, --name PSEUDONYM        Обиходное имя или псевдоним
  -c, --eid U4|U5             Идентификатор сущности. Требуется: вычисление
  -C, --extra-comment NOTE    Заметка о сущности
  -p, --passphrase PASSPHRASE Парольная фраза. Видна всему, что может
  -P, --passfrom FILE         Прочитать её из первой строки ФАЙЛА
  -e, --expiration YEARS      Лет до истечения - По умолчанию: 11
  -k, --keyserver KEYSERVER   Сервер, который этот сертификат зовёт своим - По умолчанию: hkps://keys.foopgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Оба способа передать пароль имеют свой изъян, и второй — меньший: аргумент
виден каждому процессу машины, пока тот работает.

## pgpid print_secret

```
Usage: pgpid print_secret [OPTIONS]... KEY_ID|FPR

Выгрузить и напечатать секреты OpenPGP на нескольких QR-кодах разделением
секрета по Шамиру, так поделённые, чтобы ни один лист не нёс ключа.

OPTIONS:
  -p, --passphrase PASSPHRASE Фраза, защищающая секретные части
  -P, --passfrom FILE         Прочитать её из первой строки ФАЙЛА
  -t, --printer PRINTER       Куда печатать. Пусто — изготовить листы
  -w, --with-passphrase       Напечатать фразу рядом с QR-кодами
  -W, --workdir DIRECTORY     Работать здесь, а не во временном
  -S, --split NUM             Фрагментов, от 3 до 10 - По умолчанию: 5
  -T, --threshold NUM         Фрагментов для сборки - По умолчанию: 3
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Замечание: число фрагментов должно быть больше порога.
      Когда они равны, вместо разделения Шамира идёт простое разрезание,
      и вся защита секрета держится на пароле.
      Иначе говоря: когда (фрагменты == порог), не ставить пароль или
      напечатать его — ОЧЕНЬ НЕБЕЗОПАСНО.

Фотографии в печать не идут. Резервной копии ваше лицо не нужно, а бумагу
берёт в руки тот, кто её найдёт.

```
