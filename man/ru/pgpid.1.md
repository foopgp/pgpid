# NAME

pgpid - Читает сертификаты OpenPGP и действует над ними по образцу pgpid: идентификаторы сущностей, действительность, ownertrust.

# SYNOPSIS

**pgpid** \[*OPTIONS*\]\... *ACTION *\[*ARGS*\]\...

# DESCRIPTION

Читает сертификаты OpenPGP и действует над ними по образцу pgpid:
идентификаторы сущностей, действительность, ownertrust.

## ACTIONS:

list

:   Перечислить сертификаты связки ключей

get

:   Найти сертификат, сперва обновив его

property

:   Вывести свойство vCard сертификата

sigs

:   Перечислить, кто заверил сертификат

ownertrust

:   Вывести или назначить, насколько заверяют

del

:   Удалить сертификаты, только по отпечатку

avatar

:   Извлечь изображение, которое несёт сертификат

push

:   Отправить сертификаты на серверы ключей

gen_u4

:   Вывести идентификатор от гражданского состояния

mrz_to_u4

:   Тот, что даёт зона паспорта

gen_uid

:   Вывести номер учётной записи Unix идентификатора

to_vcard

:   Вывести сертификат как vCard

email

:   Показать, добавить или отозвать несомые адреса

certify

:   Поручиться за другого

update_trustdb

:   Пересчитать доверие по подписанным поручениям

gen_key

:   Создать пару ключей по образцу PGP ID

change_passphrase

:   Сменить то, что защищает здесь секретный ключ

token_check

:   Проверить, что несёт подключённый ключ безопасности

token_retries

:   Оставшиеся попытки на кодах ключа

totoken

:   Перенести секретный ключ на ключ безопасности

change_token_code

:   Проверить или сменить его PIN либо код Admin

change_token_meta

:   Записать, что он говорит о своём владельце

print_secret

:   Напечатать секретный ключ на бумаге, фрагментами

scan

:   Собрать его обратно из фрагментов

print_card

:   Изготовить или напечатать наклейку либо карточку

## OPTIONS:

**-H**, **\--homedir** КАТАЛОГ

:   Каталог GnuPG - Переменная окружения: GNUPGHOME

**\--output-format**=*ФОРМАТ*

:   Формат вывода из {raw, info, md} - По умолч.: «raw»

**-h**, **\--help**

:   Вывести эту справку и выйти

**-V**, **\--version**

:   Вывести версию и выйти

У каждого действия есть свой **\--help**.

## pgpid list

```
Usage: pgpid list [OPTIONS]... [ОБРАЗЕЦ]

Перечисляет сертификаты связки ключей, по одному в строке.

Столбцы:
отпечаток, идентификатор сущности, адрес (главный), заверения
(необязательно), действительность, доверие, дата_создания,
дата_истечения, дата_отзыва

Одиночное тире «-» означает скрытое или неизвестное значение.

Значения действительности: certified|uncertified|expired|revoked|broken|-
Порядок важности для негодных сертификатов: broken>revoked>expired

Значения доверия: never|undefined|marginal|full|ultimate|-

ОБРАЗЕЦ, если задан, передаётся движку как есть; без него перечисляется
вся связка ключей.

OPTIONS:
  -S, --short                 Строка на адрес: отпечаток, идентификатор, адрес
                              То, что отвечает «pgpid get --no-fetch», столбец в столбец
  -L, --no-check-eid          Прежнее: не считать «broken» сертификат без внятного eid
      --count-certs           Сосчитать разных заверителей каждого сертификата и заполнить столбец *certifications* (может быть долго!)
      --hide-trust            Доверие (ownertrust) — чувствительная величина, по которой считается действительность; порой обе должны остаться личными
      --machine-readable      Выводить время (секунды от эпохи) вместо даты (iso-8601) и метки вместо читаемых слов
  -h, --help                  Вывести эту справку и выйти
```

## pgpid get

```
Usage: pgpid get [OPTIONS]... ИМЯ|АДРЕС|KEYID|U4|U5|'*'

Выводит отпечатки, адреса и идентификаторы сущностей сертификатов,
подходящих под запрос, по строке на адрес. Сперва обновляет их с серверов
ключей, если не сказано иначе.

Требуется образец поиска — «*» для всей связки ключей. Именно `list`
показывает всё, когда у него ничего не просят.

OPTIONS:
  -F, --fingerprint           Вывести только отпечатки
  -E, --email                 Вывести только адреса
  -f, --no-fetch              Не обновлять с серверов ключей и WKD
  -m, --errexit-g=N           Отказать, если подходит более N сертификатов
  -K, --keyservers СЕРВЕРЫ    Обновить с этих, через пробел
                              Пусто — ни с одного, как --no-fetch. По умолч.: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

«cert_check» нет: `list` отвечает то же, что отвечал он, дешевле.
```

## pgpid property

```
Usage: pgpid property ИМЯ [OPTIONS]... [ОБРАЗЕЦ]

Показывает значения одного свойства vCard, которое несёт сертификат, по
одному в строке, либо добавляет и отзывает их. Без ОБРАЗЦА — сертификат,
чей секретный ключ под рукой, то есть подключённый ключ безопасности.

ИМЯ — одно из: name, note, phone, address, url, lang, geo, ksprefrd.
name и note несут одно значение: добавить одно — отозвать прежнее.
Сертификат всегда сохраняет хотя бы одно имя.

Адреса — не свойства vCard: они сохраняют вид «Имя <адрес>», который
читает любая почтовая программа. Для них «pgpid email».

«ksprefrd» — сервер сертификатов, который этот сертификат зовёт своим.
Это подпакет подписи, а не uid: его заменяют, но никогда не отзывают.

OPTIONS:
  -A, --add ЗНАЧЕНИЕ          Добавить значение (повторяемо)
      --replace-to ЗНАЧЕНИЕ   То же слово, для тех, у кого значение одно
  -R, --revoke ЗНАЧЕНИЕ       Отозвать uid со ЗНАЧЕНИЕМ (повторяемо)
      --revoke-all            Отозвать все значения, кроме самого свежего
                              там, где одно должно остаться
  -y, --yes                   Считать «да»: пропустить предупреждение
      --show-unusable         Показать также значения, которые не действуют
  -K, --keyservers СЕРВЕРЫ    Отправить изменённый сертификат на эти
                              Пусто — ни на один. По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Отзыв необратим: OpenPGP хранит uid на сертификате навсегда, помеченным
как отозванный, и такой же уже никогда не добавить.
```

## pgpid sigs

```
Usage: pgpid sigs [OPTIONS]... ОТПЕЧАТОК

Перечисляет, кто заверил этот сертификат, от самого старого: дата,
идентификатор ключа, адрес. Идентификатор ключа — это то, что поиск берёт,
чтобы шагнуть дальше в сеть доверия.

Читается только uid личности (UID:urn:eid:...), потому что заверение
касается сущности, а не одного из её адресов. Сертификат без uid личности
падает на сведённый список, с уведомлением.

Собственные подписи остаются в стороне: они делают uid действующим, они
никого не заверяют.

OPTIONS:
  -a, --all-uids              Свести подписи всех uid
  -h, --help                  Вывести эту справку и выйти
```

## pgpid ownertrust

```
Usage: pgpid ownertrust [OPTIONS]... ОТПЕЧАТОК

Выводит, насколько этому сертификату доверяют заверять других: одно из
unknown, never, marginal, full, ultimate.

«undefined» назначается и читается обратно как «unknown»: движок их не
различает, и всякий, кому пришлось объяснять разницу, тоже. Одна
ступень, два написания.

OPTIONS:
  -r, --replace-to ЗНАЧЕНИЕ   Назначить ЗНАЧЕНИЕ вместо вывода
  -h, --help                  Вывести эту справку и выйти
```

## pgpid del

```
Usage: pgpid del [OPTIONS]... ОТПЕЧАТОК...

Удаляет сертификаты из связки ключей, вместе с секретной частью.

Принимаются только отпечатки — 40 или 64 шестнадцатеричных знака.
Действие, которое удаляет, не угадывает, о каком сертификате шла речь.

OPTIONS:
  -s, --secret                Удалить только секрет, сертификат оставить
  -h, --help                  Вывести эту справку и выйти
```

## pgpid avatar

```
Usage: pgpid avatar [OPTIONS]... [ИМЯ|АДРЕС|KEYID|U4|U5]

Извлекает изображение, которое несёт сертификат OpenPGP, и выводит путь
к нему. То, что действует сегодня, идёт первым: первая строка — это
аватар. Без отбора — первый секретный сертификат.

Запись требует секретного ключа сертификата и принимает только отпечаток:
отзыв не отменить, поэтому поиск никогда не должен становиться целью.
Новое изображение сперва приводится к 180x180, а изменённый сертификат
отправляется на серверы ключей по умолчанию, если не сказано иначе.

OPTIONS:
  -E, --extract-all           Вывести все изображения, включая отозванные
  -A, --replace-to ИЗОБР.     Снять действующие изображения и положить ИЗОБР.
  -R, --revoke                Только снять действующие изображения
  -K, --keyservers СЕРВЕРЫ    Отправить изменённый сертификат на эти, через
                              пробел. Пусто — ни на один. По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -W, --workdir КАТАЛОГ       Куда пишутся изображения
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти
```

## pgpid gen_u4

```
Usage: pgpid gen_u4 [OPTIONS]...

Выводит идентификатор сущности, который даёт гражданское состояние:
последнюю часть фамилии, два первых имени, дату рождения и страну.

OPTIONS:
  -s, --surname ФАМИЛИЯ            Фамилия при рождении
  -g, --given-names ИМЕНА          Имена при рождении, через пробел или запятую
  -d, --birth-date ГГГГ-ММ-ДД      Дата рождения
  -c, --birth-country КОД          Трёхбуквенный код страны места рождения
  -h, --help                       Вывести эту справку и выйти
  -V, --version                    Вывести версию и выйти

Требуется всё: спрашивать о недостающем — дело того, у кого есть кого
спросить.
```

## pgpid mrz_to_u4

```
Usage: pgpid mrz_to_u4 [OPTIONS]... MRZ...

Выводит идентификатор сущности, который даёт машиночитаемая зона
паспорта. В зоне 88 знаков в двух строках; пробелы и переводы строк
пропускаются, поэтому её можно вставить как считали.

OPTIONS:
  -d, --birth-date ГГГГ-ММ-ДД  Дата рождения, если двух цифр не хватает
  -u, --uncheck                Сообщить о неверной контрольной цифре, не отказывая
  -h, --help                   Вывести эту справку и выйти
  -V, --version                Вывести версию и выйти

Примерно каждый пятый паспорт даёт неверный идентификатор: фамилия,
урезанная, чтобы уместиться, имя, изменённое после рождения, иная
транслитерация, или год, который двум цифрам не разместить. Это нужно
проверять.
```

## pgpid gen_uid

```
Usage: pgpid gen_uid [OPTIONS]... U4|U5|СТРОКА

Выводит номер учётной записи Unix, который даёт идентификатор сущности,
между 262144 и 2147483646. Один и тот же идентификатор всегда даёт один и тот же
номер, на любой машине — это и позволяет открыть учётную запись в другом
месте по одному лишь сертификату.

OPTIONS:
  -f, --free-input            Принять любую строку, не только идентификатор
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Спрашивать гражданское состояние в разговоре — дело вызывающего: это
читает, что ему дали, и ничего больше.
```

## pgpid email

```
Usage: pgpid email [OPTIONS]... [ИМЯ|АДРЕС|KEYID|U4|U5]

Показывает адреса, которые несёт сертификат, либо добавляет и отзывает
их. Без цели — тот, которому принадлежит подключённая карта.

Показываются только адреса, которые ещё действуют — ни отозванные, ни
истёкшие, ни те, чья собственная подпись больше не держит.

OPTIONS:

      --revoke-all            Отозвать все адреса, кроме самого свежего
  -y, --yes                   Считать «да»: пропустить предупреждение
  -N, --name ИМЯ              Имя перед добавляемым адресом
                              По умолчанию: FN: сертификата, иначе местная часть
  -c, --certs-count           Считать также заверения каждого адреса
      --show-unusable         Показать также адреса, которые больше не действуют
      --info                  Вывести пары ключ=значение, годные для bash
  -K, --keyservers СЕРВЕРЫ    Отправить изменённый сертификат на эти
                              Пусто — ни на один. По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти

Отзыв необратим: OpenPGP хранит адрес на сертификате навсегда, помеченным
как отозванный, и такой же уже никогда не добавить.
```

## pgpid certify

```
Usage: pgpid certify [OPTIONS]... ОТПЕЧАТОК [U4|U5]

Поручиться за другого: заявить, что этот сертификат принадлежит ему.

ОТПЕЧАТОК — это отпечаток целиком, сорок знаков, считанный с карты
другого человека и сверенный с ней — никогда не образец поиска, потому
что заверение не отзывается. Указание ещё и идентификатора требует, чтобы
сертификат его нёс, и отказывает иначе.

Заверение обязывает. Оно строит ваше доброе имя и тратит её, если делать
это не глядя.

OPTIONS:
  -u, --use-privkey ИМЯ|KEYID   Заверить этим ключом
                                По умолчанию: тот, которому принадлежит карта
  -E, --all-emails              Заверить также каждый uid с адресом,
                                для программ, которые ждут его там
  -R, --revoke                  Отозвать свои прежние заверения
  -o, --ownertrust ЗНАЧЕНИЕ     Насколько они, в свою очередь, заверяют других
                                {undefined,marginal,full,never} — умолч.: marginal
  -l, --local                   Заверить без вывоза — полезно для проб
  -K, --keyservers СЕРВЕРЫ      Отправить итог на эти, через пробел
                                Пусто — ни на один. По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                    Вывести эту справку и выйти
  -V, --version                 Вывести версию и выйти

Возвращаемое значение:
-   0 Без ошибок
-   2 Ошибка довода или употребления
- 140 Нечем заверять — укажите ключ через --use-privkey
- 141 Ни один сертификат не несёт этот отпечаток
- 142 Заверять самого себя — не новость! ;-)
- 143 Этот сертификат не несёт этот идентификатор
```

## pgpid update_trustdb

```
Usage: pgpid update_trustdb [OPTIONS]... [OWNERTRUST.GPG]...

Пересчитывает базу доверия GnuPG после применения поручений, которые
несут заданные файлы.

Каждый файл должен быть подписанным сообщением OpenPGP, а подписавший его
должен быть уже действителен, когда придёт его черёд — потому порядок
файлов входит в то, что они значат. Сказанное ими о ваших собственных
ключах пропускается: доверие можно распространить на других, но не
переопределить ваше.

OPTIONS:
      --batch                 Пересчитать, не спрашивая об остальных ключах
  -q, --quiet                 Только ошибки и предупреждения
  -h, --help                  Вывести эту справку и выйти
  -V, --version               Вывести версию и выйти
```

## pgpid gen_key

```
Usage: pgpid gen_key [OPTIONS]... АДРЕС

Создаёт пару ключей OpenPGP по образцу PGP ID и выводит три полученных
отпечатка: главный ключ, который подписывает и заверяет, тот, который
расшифровывает, и тот, который подтверждает.

OPTIONS:
  -N, --name ПСЕВДОНИМ             Обиходное имя или псевдоним
                                   По умолчанию: часть АДРЕСА до «@»
  -c, --eid U4|U5                  Идентификатор сущности. Требуется: вычисление
                                   требует гражданского состояния, о котором просят
  -C, --extra-comment ЗАМЕТКА      Заметка о сущности
  -p, --passphrase ФРАЗА           Парольная фраза. Видна всему, что может
                                   прочитать список процессов этой машины
  -P, --passfrom ФАЙЛ              Прочитать её из первой строки ФАЙЛА
                                   (fifo, что-то на tmpfs, /dev/stdin)
  -e, --expiration ЛЕТ             Лет до истечения - По умолчанию: 11
  -k, --keyserver СЕРВЕР           Сервер, который этот сертификат зовёт своим
                                   По умолчанию: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                       Вывести эту справку и выйти
  -V, --version                    Вывести версию и выйти

У обоих способов передать парольную фразу есть свой изъян, и у второго
их меньше: довод виден каждому процессу машины, пока этот работает.
```

## pgpid change_token_code

```

Проверяет или меняет PIN либо код Admin подключённого ключа безопасности.
```

## pgpid print_secret

```
Usage: pgpid print_secret [OPTIONS]... КЛЮЧ

Печатает секретный ключ OpenPGP как QR-коды, разделённый так, чтобы ни
один лист не нёс его целиком. По умолчанию пять фрагментов, любые три из
которых его восстанавливают.

OPTIONS:
  -p, --passphrase ФРАЗА         Фраза, защищающая секретные части
  -P, --passfrom ФАЙЛ            Прочитать её из первой строки ФАЙЛА
  -t, --printer ПРИНТЕР          Куда печатать. Пусто — изготовить листы
                                 и ничего не отправлять, они остаются на месте
  -w, --with-passphrase          Напечатать фразу рядом с QR-кодами
                                 Удобнее, и секрет больше не разделён
  -W, --workdir КАТАЛОГ          Работать здесь, а не во временном
                                 Его содержимое придётся потом уничтожить
  -S, --split ЧИСЛО              Фрагментов к изготовлению - По умолчанию: 5
  -T, --threshold ЧИСЛО          Фрагментов для сборки - По умолчанию: 3
  -h, --help                     Вывести эту справку и выйти
  -V, --version                  Вывести версию и выйти

Когда --split равен --threshold, разделения секрета нет: фрагменты — это
идущие подряд куски, и каждый выдаёт свою часть. Всё держится тогда на
парольной фразе, а напечатать её рядом — не оставить ничего.

Фотографии в печать не идут. Резервной копии ваше лицо не нужно, а бумагу
берёт в руки тот, кто её найдёт.
```
