# NAME

pgpid - Ler e agir sobre certificados OpenPGP segundo o modelo pgpid: identificadores de entidade, validade, ownertrust.

# SYNOPSIS

**pgpid** \[*OPTIONS*\]\... *ACTION *\[*ARGS*\]\...

# DESCRIPTION

Ler e agir sobre certificados OpenPGP segundo o modelo pgpid:
identificadores de entidade, validade, ownertrust.

## ACTIONS:

list

:   Listar os certificados do porta-chaves

get

:   Procurar um certificado, atualizando-o antes

property

:   Imprimir uma propriedade vCard de um certificado

sigs

:   Listar quem certificou um certificado

ownertrust

:   Imprimir ou definir até onde se certifica

del

:   Apagar certificados, só por impressão digital

avatar

:   Extrair a imagem que um certificado traz

push

:   Enviar certificados aos servidores de chaves

gen_u4

:   Imprimir o identificador que um estado civil dá

mrz_to_u4

:   O que a zona de um passaporte dá

gen_uid

:   Imprimir o número de conta Unix de um identificador

to_vcard

:   Imprimir um certificado como vCard

email

:   Mostrar, acrescentar ou revogar os endereços

certify

:   Responder por outra pessoa

update_trustdb

:   Recalcular a confiança a partir de delegações assinadas

gen_key

:   Gerar um par de chaves à maneira PGP ID

change_passphrase

:   Mudar o que protege uma chave secreta aqui

token_check

:   Verificar o que a chave de segurança ligada traz

token_retries

:   Tentativas restantes nos códigos da chave

totoken

:   Mover uma chave secreta para uma chave de segurança

change_token_code

:   Verificar ou mudar o seu PIN ou código Admin

change_token_meta

:   Escrever o que ela diz do seu portador

print_secret

:   Pôr uma chave secreta em papel, em fragmentos

scan

:   Recompô-la a partir dos fragmentos

print_card

:   Produzir ou imprimir um autocolante ou um cartão

## OPTIONS:

**-H**, **\--homedir** DIRETÓRIO

:   Diretório GnuPG - Variável de ambiente: GNUPGHOME

**\--output-format**=*FORMATO* Formato de saída entre {raw, info, md} -
Omissão: «raw»

**-h**, **\--help**

:   Imprimir esta ajuda e sair

**-V**, **\--version**

:   Imprimir a versão e sair

Cada ação tem o seu próprio **\--help**.

## pgpid list

```
Usage: pgpid list [OPTIONS]... [PADRÃO]

Listar os certificados do porta-chaves, um por linha.

Colunas:
impressão digital, identificador de entidade, endereço (primário),
certificações (opcional), validade, credibilidade, data_de_criação,
data_de_caducidade, data_de_revogação

Um traço só «-» significa valor oculto ou desconhecido.

Valores de validade: certified|uncertified|expired|revoked|broken|-
Ordem de importância para os certificados inutilizáveis: broken>revoked>expired

Valores de credibilidade: never|undefined|marginal|full|ultimate|-

PADRÃO, se dado, é passado tal e qual ao motor; sem ele lista-se todo o
porta-chaves.

OPTIONS:
  -S, --short                 Uma linha por endereço: impressão, endereço, identificador
                              O que «bl-pgpid get --no-fetch» responde, coluna a coluna
  -L, --no-check-eid          Antigo: não considerar «broken» um certificado sem eid coerente
      --count-certs           Contar os certificadores distintos de cada certificado e preencher a coluna *certifications* (pode demorar!)
      --hide-trust            A credibilidade (o ownertrust) é sensível e serve para calcular a validade — às vezes ambas devem ficar privadas
      --machine-readable      Emitir um tempo (segundos desde a época) em vez de uma data (iso-8601), e marcas em vez de palavras legíveis
  -h, --help                  Imprimir esta ajuda e sair
```

## pgpid get

```
Usage: pgpid get [OPTIONS]... NOME|ENDEREÇO|KEYID|U4|U5|'*'

Imprimir as impressões digitais, endereços e identificadores de entidade
dos certificados que correspondem ao pedido, uma linha por endereço.
Atualiza-os antes a partir dos servidores de chaves, salvo indicação em
contrário.

Exige-se um padrão de pesquisa — «*» para todo o porta-chaves. É `list`
que mostra tudo quando nada se lhe pede.

OPTIONS:
  -F, --fingerprint           Imprimir só as impressões digitais
  -E, --email                 Imprimir só os endereços
  -f, --no-fetch              Não atualizar dos servidores nem dos WKD
  -m, --errexit-g=N           Falhar se corresponderem mais de N certificados
  -K, --keyservers SERVIDORES Atualizar destes, separados por espaços
                              Vazio para nenhum, como --no-fetch. Omissão: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Imprimir esta ajuda e sair
  -V, --version               Imprimir a versão e sair

Não há «cert_check»: `list` responde o que respondia, por menos.
```

## pgpid property

```
Usage: pgpid property NOME [OPTIONS]... [PADRÃO]

Mostrar os valores de uma propriedade vCard que um certificado traz, um
por linha, ou acrescentá-los e revogá-los. Sem PADRÃO, o certificado cuja
chave secreta está à mão — a chave de segurança ligada.

NOME é um de: name, note, phone, address, url, lang, geo, ksprefrd.
name e note trazem um só valor: acrescentar um revoga o anterior. Um
certificado guarda sempre pelo menos um nome.

Os endereços não são propriedades vCard — guardam a forma
«Nome <endereço>» que todo o programa de correio lê. Veja «pgpid email».

«ksprefrd» é o servidor de certificados que este certificado diz seu. É
um subpacote de assinatura e não um uid: substitui-se, nunca se revoga.

OPTIONS:
  -A, --add VALOR             Acrescentar um valor (repetível)
      --replace-to VALOR      A mesma palavra, para as de valor único
  -R, --revoke VALOR          Revogar o uid que traz VALOR (repetível)
      --revoke-all            Revogar todos os valores, salvo o mais recente
                              onde um tem de ficar
  -y, --yes                   Assumir sim: saltar o aviso de irreversibilidade
      --show-unusable         Mostrar também os valores que já não valem
  -K, --keyservers SERVIDORES Enviar o certificado alterado a estes
                              Vazio para nenhum. Omissão: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                  Imprimir esta ajuda e sair
  -V, --version               Imprimir a versão e sair

Revogar é irreversível: o OpenPGP guarda o uid para sempre no
certificado, marcado revogado, e um idêntico nunca mais poderá ser
acrescentado.
```

## pgpid sigs

```
Usage: pgpid sigs [OPTIONS]... IMPRESSÃO

Listar quem certificou esse certificado, do mais antigo ao mais recente:
data, identificador de chave, endereço. O identificador de chave é o que
uma pesquisa toma para avançar um passo na rede de confiança.

Só se lê o uid de identidade (UID:urn:eid:...), porque uma certificação
diz respeito à entidade e não a um dos seus endereços. Um certificado sem
uid de identidade recai na lista fundida, com um aviso.

As autoassinaturas ficam de fora: fazem valer um uid, não certificam
ninguém.

OPTIONS:
  -a, --all-uids              Fundir as assinaturas de todos os uid
  -h, --help                  Imprimir esta ajuda e sair
```

## pgpid ownertrust

```
Usage: pgpid ownertrust [OPTIONS]... IMPRESSÃO

Imprimir até onde se confia nesse certificado para certificar outros: um
de unknown, never, marginal, full, ultimate.

«undefined» define-se e relê-se «unknown»: o motor não os distingue, e
quem já teve de explicar a diferença também não. Um degrau, duas grafias.

OPTIONS:
  -r, --replace-to VALOR      Defini-lo como VALOR em vez de o imprimir
  -h, --help                  Imprimir esta ajuda e sair
```

## pgpid del

```
Usage: pgpid del [OPTIONS]... IMPRESSÃO...

Apagar certificados do porta-chaves, parte secreta incluída.

Só se aceitam impressões digitais — 40 ou 64 carateres hexadecimais. Uma
ação que apaga não adivinha que certificado se queria.

OPTIONS:
  -s, --secret                Apagar só o segredo, guardar o certificado
  -h, --help                  Imprimir esta ajuda e sair
```

## pgpid avatar

```
Usage: pgpid avatar [OPTIONS]... [NOME|ENDEREÇO|KEYID|U4|U5]

Extrai a imagem que um certificado OpenPGP traz e imprime o seu caminho.
A que vale hoje vem primeiro: a primeira linha é pois o avatar. Sem
seletor, o primeiro certificado secreto.

Escrever exige a chave secreta do certificado e só aceita uma impressão
digital: uma revogação não se desfaz, portanto uma pesquisa nunca deve
tornar-se um alvo. Uma imagem nova é primeiro levada a 180x180, e o
certificado alterado é enviado aos servidores de chaves por omissão,
salvo indicação em contrário.

OPTIONS:
  -E, --extract-all           Imprimir todas as imagens, revogadas incluídas
  -A, --replace-to IMAGEM     Retirar as imagens que valem e pôr IMAGEM
  -R, --revoke                Só retirar as imagens que valem
  -K, --keyservers SERVIDORES Enviar o certificado alterado a estes, separados
                              por espaços. Vazio para nenhum. Omissão: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -W, --workdir DIRETÓRIO     Onde as imagens são escritas
  -h, --help                  Imprimir esta ajuda e sair
  -V, --version               Imprimir a versão e sair
```

```
Usage: pgpid mrz_to_u4 [OPTIONS]... MRZ...

Imprimir o identificador de entidade que a zona de leitura ótica de um

## pgpid certify

```
Usage: pgpid certify [OPTIONS]... IMPRESSÃO [U4|U5]

Responder por outra pessoa: declarar que este certificado é dela.

IMPRESSÃO é a impressão digital inteira, quarenta carateres, lida no
cartão da outra pessoa e conferida contra ele — nunca um padrão de
pesquisa, porque uma certificação não se retira. Dar também o
identificador exige que o certificado o traga, e recusa caso contrário.

Certificar compromete. Constrói o seu crédito, e gasta-o se o fizer sem
olhar.

OPTIONS:
  -u, --use-privkey NOME|KEYID  Certificar com esta chave
                                Omissão: aquela de que depende o cartão
  -E, --all-emails              Certificar também todo o uid com endereço,
                                para os programas que o esperam aí
  -R, --revoke                  Revogar as suas certificações anteriores
  -o, --ownertrust VALOR        Até onde certificam outros, por sua vez
                                {undefined,marginal,full,never} — omissão: marginal
  -l, --local                   Certificar sem exportar — útil para ensaiar
  -K, --keyservers SERVIDORES   Enviar o resultado a estes, separados por
                                espaços. Vazio para nenhum. Omissão: hkps://keys.foopgp.org hkps://keys.openpgp.org
  -h, --help                    Imprimir esta ajuda e sair
  -V, --version                 Imprimir a versão e sair

Valor de retorno:
-   0 Nenhum erro
-   2 Erro de argumento ou de uso
- 140 Nada com que certificar — diga que chave com --use-privkey
- 141 Nenhum certificado traz essa impressão digital
- 142 Autocertificar-se não tem nada de novo! ;-)
- 143 Esse certificado não traz esse identificador
```

## pgpid update_trustdb

```
Usage: pgpid update_trustdb [OPTIONS]... [OWNERTRUST.GPG]...

Recalcular a base de confiança do GnuPG, depois de aplicar as delegações
que os ficheiros dados trazem.

Cada ficheiro tem de ser uma mensagem OpenPGP assinada, e quem a assinou
tem de já ser válido quando chegar a sua vez — por isso a ordem dos

chaves é ignorado: pode estender-se a confiança a outros, não redefinir a
sua.

OPTIONS:
      --batch                 Recalcular sem perguntar pelas outras chaves
  -q, --quiet                 Só erros e avisos
  -h, --help                  Imprimir esta ajuda e sair
  -V, --version               Imprimir a versão e sair
```

## pgpid gen_key

```
Usage: pgpid gen_key [OPTIONS]... ENDEREÇO

Gerar um par de chaves OpenPGP à maneira PGP ID, e imprimir as três

## pgpid token_check

```
Usage: pgpid token_check [OPTIONS]...

Dizer se a chave de segurança ligada está configurada para trazer um
PGP ID, e o que contém. Tenta obter o certificado indicado nos metadados
da chave, salvo indicação em contrário.

OPTIONS:
  -f, --no-fetch              Não obter o certificado a partir do URL
  -p, --cert-fpr              Impressão digital da chave de certificação
  -i, --info                  Imprimir cada campo como chave='valor'

Devolve 0 quando a chave traz uma identidade completa, senão 100 mais o
número de campos em falta — 107 é pois uma chave que nada traz, isto é
uma chave virgem e não uma avariada.
```

## pgpid change_token_meta

```
Usage: pgpid change_token_meta [OPTIONS]... METADADO

Escrever uma das três coisas que uma chave de segurança diz do seu
portador. Qual, lê-se em METADADO:

  um endereço       o nome do portador (DO 5B)
  um URL http(s)    onde vive o certificado público (DO 5F50)
  duas letras       a língua preferida, ISO 639-1 (DO 5F2D)

Cada uma é conferida antes de ser escrita: o endereço tem de ser um dos
que o certificado ainda traz, e o URL tem de servir um certificado que
traga as três subchaves deste cartão.

OPTIONS:
  -A, --admincode CÓDIGO       O código Admin, oito dígitos em geral
  -p, --admincodefrom FICHEIRO Lê-lo na primeira linha de FICHEIRO
  -h, --help                   Imprimir esta ajuda e sair
  -V, --version                Imprimir a versão e sair
```

## pgpid print_secret

```
Usage: pgpid print_secret [OPTIONS]... CHAVE

Imprimir uma chave secreta OpenPGP como códigos QR, repartida para que
nenhuma folha a traga sozinha. Por omissão cinco fragmentos dos quais
três quaisquer a reconstroem.

OPTIONS:
  -p, --passphrase FRASE         A frase que protege as partes secretas
  -P, --passfrom FICHEIRO        Lê-la na primeira linha de FICHEIRO
  -t, --printer IMPRESSORA       Onde imprimir. Vazio para produzir as folhas
                                 sem enviar nada — ficam no lugar
  -w, --with-passphrase          Imprimir a frase ao lado dos códigos QR
                                 Mais cómodo, e o segredo já não é repartido
  -W, --workdir DIRETÓRIO        Trabalhar aqui em vez de num temporário
                                 O seu conteúdo terá de ser triturado depois
  -S, --split NÚMERO             Fragmentos a produzir - Omissão: 5
  -T, --threshold NÚMERO         Fragmentos para recompor - Omissão: 3
  -h, --help                     Imprimir esta ajuda e sair
  -V, --version                  Imprimir a versão e sair

Com --split igual a --threshold não há repartição de segredo: os
fragmentos são pedaços consecutivos e cada um deixa escapar a sua parte.
Tudo assenta então na frase-passe, e imprimi-la ao lado não deixa nada.

As fotografias não vão para a impressão. Uma salvaguarda não precisa do
seu rosto, e o papel é manuseado por quem o encontra.
```

```

Recompor uma chave secreta OpenPGP a partir dos códigos QR das IMAGEM...,

OPTIONS:
  -p, --passphrase FRASE        A frase que protege as partes secretas
  -P, --passfrom FICHEIRO       Lê-la na primeira linha de FICHEIRO
  -W, --workdir DIRETÓRIO       Trabalhar aqui em vez de num temporário

  -h, --help                    Imprimir esta ajuda e sair
  -V, --version                 Imprimir a versão e sair

```
